# Leaving India vote

Two landscape result cards rebuilt from the source Mentimeter screenshots in
the Contrarian Club visual system.

The source pre-debate chart shows 7, 5, and 5 responses. Its participant header
says 28, so the artwork converts the 17 responses shown to 41.2%, 29.4%, and
29.4% rather than treating 28 as the response count. The post-debate chart
preserves the displayed 70%, 30%, and 0% values.

Render from `posters/`:

```bash
node works/2026-08-10-leaving-india-vote/render.cjs
```
